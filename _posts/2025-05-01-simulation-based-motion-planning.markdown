This project presents a simulation-based design of an automated cargo handling system using a 6-DOF Universal Robots UR10 robotic arm in CoppeliaSim. The control system is built on a distributed, multi-script architecture in Lua, coordinating the robot arm with conveyor actuators and cargo spawn triggers *(Manuscript in Preparation)*.
