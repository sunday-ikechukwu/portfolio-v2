This project presents an implementation of the Bug2 reactive navigation algorithm from scratch using ROS 2 Humble and Gazebo simulation. The primary objective is to analyze the behavior, edge cases, and systemic limitations of purely sensor-driven reactive planning in structured and dynamic maze environments, establishing a deterministic baseline for future learning-based local planners.
